# 欢迎使用 Ananke - 字卡小手机

一个纯前端的虚拟手机式字卡互动网页应用，支持自定义手机桌面、字卡库与模块化系统。

## 🌐 在线体验
你可以直接在浏览器中打开体验：
👉 [点击这里访问](https://tenebrae-m.github.io/Ananke/)
或者复制到您的仓库中自己部署

## 🛠️ 源码与二改说明

如果你想进行二次开发或修改代码，请在本仓库根目录下载 **`Ananke-源码.zip`** 文件。
二改必须标明原作者@Nyx（小红书：42894201185）

**本地运行方法：**
1. 解压下载的 zip 文件。
2. 请确保你的电脑已安装 Node.js 环境。
3. 在解压后的文件夹内打开终端（命令行），运行 `npm install` 安装依赖。
4. 运行 `npm run dev` 即可在本地预览和调试。
5. 修改代码后，运行 `npm run build` 即可生成用于部署的 `dist` 文件夹。
